# CRESCI Avatar Standard v3

Multi-resolution HD dressed masters for the approved male and female CRESCI avatars.

- `master`: 1024×1536 — authoring and future layer production.
- `runtime`: 512×768 — main Character screen.
- `compact`: 256×384 — creator, shop, inventory and small profile panels.

All variants are transparent, use a 2:3 canvas and share proportionally identical feet-center anchors. Select the closest prepared variant for the viewport instead of asking the browser to resize the 1024×1536 master. These are dressed masters; the complete creator/shop layer rebuild is the next production phase.
