# CRESCI HD Creator + Shop v4 — production

Kompletna paczka po oczyszczeniu masek wszystkich slotów. Przezroczyste piksele mają wyzerowane RGB, więc skalowanie w GUI nie tworzy kolorowych obwódek.

Używaj `runtime` 512x768 w głównym avatarze i `compact` 256x384 w małym GUI. Każdą warstwę rysuj na `(0,0)` i zachowuj kolejność z manifestu. Nie stosuj filtrów, cieni ani `cover`; używaj `contain` i `image-rendering: pixelated`.
