# CRESCI Avatar HD Proof v2

Quality proof for the proposed 512×768 CRESCI Avatar Standard v2. This is not yet the complete layered creator/shop pack. The two dressed masters are intended for an in-app quality and scale test before rebuilding every body, eyes, hair and wearable layer.

Canvas: 512×768. Feet-center anchor: `(256,758)`. Render with no CSS filtering; when scaling, use integer or half-integer display sizes where practical.
